# 用户展示模板（display-templates）

面向用户的菜单与表格，按场景原样展示。

## 原材料提供菜单（Step 2 开头）

```
原材料怎么提供？

  [A] 飞书自动采集（推荐）
      输入姓名，自动拉取消息记录 + 文档 + 多维表格

  [B] 钉钉自动采集
      输入姓名，自动拉取文档 + 多维表格
      消息记录通过浏览器采集（钉钉 API 不支持历史消息）

  [C] 飞书链接
      直接给文档/Wiki 链接（浏览器登录态 或 MCP）

  [D] 上传文件
      PDF / 图片 / 导出 JSON / 邮件 .eml

  [E] 直接粘贴内容
      把文字复制进来

可以混用，也可以跳过（仅凭手动信息生成）。
```

## 飞书链接读取方式菜单（方式 C）

```
检测到飞书链接，选择读取方式：

  [1] 浏览器方案（推荐）
      复用你本机 Chrome 的登录状态
      [OK] 内部文档、需要权限的文档都能读
      [OK] 无需配置 token
      [WARN] 需要本机安装 Chrome + playwright

  [2] MCP 方案
      通过飞书 App Token 调用官方 API
      [OK] 稳定，不依赖浏览器
      [OK] 可以读消息记录（需要群聊 ID）
      [WARN] 需要先配置 App ID / App Secret
      [WARN] 内部文档需要管理员给应用授权

选择 [1/2]：
```
