# 交付前自检

出稿前逐条核对。**每一条都是硬性阻断项，不是建议。** 有任一条不过，先修再交付。

## A. 模式纪律

- [ ] 制品属于 `web` 还是 `platform` 已明确，且**只用一套语言**
- [ ] 没有把 `web` 的通版瓦片、Action Blue 单一强调色带进 `platform` 制品
- [ ] 没有把 `platform` 的系统色族、控件密度带进 `web` 制品
- [ ] 关于玻璃/材质：`web` 当常规层次手段，`platform` 默认实色 —— 按当前 mode 走，没互相借

## B. 动效（参数以 `apple/motion.md` 为唯一权威）

- [ ] 每个动画都能通过"该不该动"的频率闸门（每天 100+ 次的动作**不做动画**）
- [ ] 每个动画能用反馈/空间一致性/状态指示/防突变/说明/愉悦之一命名
- [ ] **无 `ease-in`**（任何位置）
- [ ] **无贝塞尔伪弹簧**（`cubic-bezier(0.175,0.885,0.32,1.275)`、`cubic-bezier(0.68,-0.55,0.265,1.55)`）
- [ ] 缓动取自三个合法 token：`--ease-out` / `--ease-in-out` / `--ease-drawer`
- [ ] UI 时长 ≤ 300ms（有理由的营销/说明类除外）
- [ ] 无 `transition: all`；只动 `transform` / `opacity`（`clip-path` 获准，手风琴的 `height` 容忍）
- [ ] 无 `scale(0)` 入场 —— 从 `scale(0.9–0.97)` + `opacity: 0` 起
- [ ] 触发器锚定的 popover/菜单/tooltip 有 `transform-origin`；模态保持居中
- [ ] 快速可连触的元素（toast、开关）用 transition 而非 keyframes
- [ ] 进和出走同一路径
- [ ] 装饰性动画不阻塞交互

## C. 无障碍（随动画一起交付，不是后续补）

- [ ] `prefers-reduced-motion: reduce` 有**更温和的变体**（去掉位移、保留透明度/颜色），**不是** `0.01ms !important` 一刀切
- [ ] `:hover` 运动被 `@media (hover: hover) and (pointer: fine)` 门控
- [ ] 文字对比度：正文 4.5:1，大字 3:1
- [ ] **压在影像上的文字单独验过。** 任何走 `background-color` 的对比度工具都量不到这一层 —— scrim 是渐变、底下是照片，工具只会读到元素自身的背景色然后给你一个假 PASS。这类文字必须实际渲染出来看（`llm-vision-mcp` 的 `analyze_image` 或 `describe_ui`），或在图最亮的那块像素上手工核。
- [ ] **`platform` 浅色模式：正文级文字用了 `-aa` 变体**（Apple 系统色原值作正文只有 3.26–4.02，不达 AA）；图标/分隔线/大字/填充可用原色。判据见 `platform-mode.md` 的「对比度双轨」
- [ ] 浮层（Sheet / Alert / 模态）**有焦点陷阱** —— 打开移入焦点、关闭归还、`Tab` 不逃逸到背后的页面。起步包未做 trap，真实项目必补
- [ ] 语义化标签（`<button>` / `<nav aria-label>` / `<main>`）与 `aria-*` 完整
- [ ] 键盘可达，`:focus-visible` 有可见样式
- [ ] `platform` 模式触控目标 ≥ 44×44pt

## D. 排版

- [ ] 字距随尺寸变化，**没有用单一 `letter-spacing` 通吃所有字号**
- [ ] 大标题用负字距，正文接近 0
- [ ] 行高与尺寸反向（大标题紧、正文松）
- [ ] 层级由字重 + 字号 + 行高**成套**构成，不只靠字号
- [ ] `web` 模式：正文 17px（不是 16px），字重阶梯 300/400/600/700，**无 500**
- [ ] `platform` 模式：≥20pt 用 Display、<20pt 用 Text
- [ ] 间距用 `rem`/`em` 而非固定 px（尊重用户的文字大小设置）
- [ ] 非 Apple 平台走 Inter 替代方案（`ss03` + 显示尺寸额外 `-0.01em` + 正文行高 1.44）

## E. 视觉（按 mode 分别核对）

**web 模式**

- [ ] **影像来源已明确**，且按优先级取：用户真实产品图 > 生成 > 占位
- [ ] **没有用生成图冒充产品渲染图**（AI 合成的人造产品图会摧毁这套奢侈语境的信服力）
- [ ] 主视觉通版**不切圆角**；产品渲染图**带透明**且承接全系统唯一那处阴影；配件 1:1 方裁 + `lg` 圆角
- [ ] 首屏主视觉 `eager`，其余 `lazy`；`srcset` + `sizes` 完整
- [ ] 只有一个强调色 `#0066cc`；浅色面上没用 `#2997ff`
- [ ] 正文色 `#1d1d1f`，不是纯黑
- [ ] **全系统只有一处投影**，且只给产品渲染图 —— 卡片/按钮/文字上无阴影
- [ ] 无装饰性渐变
- [ ] 明暗瓦片交替，颜色变化充当分隔；瓦片无圆角
- [ ] `pill` 只给主 CTA 和应读作"动作"的元素
- [ ] 所有按钮按下态 `transform: scale(0.95)`

**platform 模式**

- [ ] 颜色提供**明暗两套**（`prefers-color-scheme`）
- [ ] 嵌套圆角满足同心等式：内圆角 + 内边距 = 外圆角
- [ ] 标签栏有文字标签，不是纯图标
- [ ] 玻璃效果仅按需使用，且带 `backdrop-filter` 不支持的降级
- [ ] 图标用 SVG，**没用私有区码点字符**

## F. 工程

- [ ] 所有文件为 **LF** 行尾，无 CRLF
- [ ] 无 Emoji（用 `[OK]` / `[FAIL]` / `[NOTE]` 等纯文本标记）
- [ ] 多文件原型通过 **HTTP** 打开（`file://` 会静默加载失败），已验证 URL 可开
- [ ] 截图前跑过视觉探针；探针不过则改用文本 + DOM 证据验证
- [ ] 若引入了 `web-tokens.css` / `platform-tokens.css`，无未使用的工具类残留

## G. 诚实性

- [ ] 依赖了本技能当前缺失的能力时**已明确告知用户**，没有假装调用
- [ ] 交付物是真的跑过、看过，不是"应该没问题"

## H. 工作方法

- [ ] 动手前取过设计上下文（`starter-components/` 起步组件、用户已有代码库或设计系统、截图、Figma），**不是从零开搓**
- [ ] 拿不到上下文时**向用户要过**，而不是闷头编造
- [ ] 三件含糊处都问清了：**mode（web / platform）**、有无既有品牌或设计系统、有无真实产品图
- [ ] 给了 **3+ 变体**，且变异发生在**内容编排 / 影像选择 / 节奏密度**等真实维度上 —— 不是换强调色冒充变体
- [ ] 并排比较用的是**中性呈现框架**（中性灰底 + 带标签的白色自适应圆角卡），**没有**把 Apple token 套到对比框上（那会让每块框都在暗示同一个答案）
