# 输出模板（output-templates）

阶段 1 结尾的需求快照与阶段 2 的提示词输出模板。使用时精确按此结构。

## 需求快照（阶段 1 结束）

```
【需求快照】
背景与诱因：[从对话中提取]
核心目标：[从对话中提取]
受众与场景：[从对话中提取]
关键流程：[从对话中提取]
硬性约束：[从对话中提取]
成功标准：[从对话中提取]
用户确认：是/否
```

## 提示词输出模板（阶段 2）

**精确**输出此结构。每个模块都必须出现，即使其内容为 `[未指定]`：

```markdown
# [标题：从核心目标中提取约 5 个字的摘要；如无法提取，写"任务"]

## 角色
[来自受众与场景；如无，[未指定]]

## 背景
[背景与诱因，原文照录]

## 目标
[核心目标，原文照录]

## 执行步骤
1. [步骤 1]
2. [步骤 2]
...

## 输出要求
- 格式：[从成功标准中提取；如无，[未指定]]
- 长度：[从成功标准中提取；如无，[未指定]]
- 风格：[从成功标准中提取；如无，[未指定]]

## 约束
- [约束 1]
- [约束 2]
...
[如果没有约束，写：[未指定]]
```
